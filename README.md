# coding-exercises

A collection of DSA (Data Structures & Algorithms) exercises sourced from [AlgoMonster](https://algo.monster) and [LeetCode](https://leetcode.com).

## Setup

This project uses [uv](https://docs.astral.sh/uv/) for dependency management.

```bash
uv sync
```

## Structure

| Folder | Topic |

| [01-overview](./01-overview/) | Introduction and study roadmap |
